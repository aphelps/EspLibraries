# EspLibraries
Various Libraries for use with Esp32 modules

## Libraries

* **[WiFiBase](WiFiBase/README.md)** — WiFi bring-up with a fallback access
  point and a small REST management server. The README covers both integrating
  it into firmware and getting a device that uses it onto a network.
* **TCPSocket** — a TCP implementation of the HMTL Socket API.
